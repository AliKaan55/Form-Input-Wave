# Form Input Wave

Bu proje, giriş kutularına (Email / Password) tıklandığında **etiket harflerinin dalgalı şekilde yukarı veya aşağı kaydığı** şık bir animasyon içerir.  
Kullanıcı deneyimini daha eğlenceli hale getiren modern bir form tasarımıdır.

##  Özellikler
- Input alanına odaklanıldığında harflerin dalgalı animasyonu
- Temiz ve modern login arayüzü
- Responsive tasarım (mobil uyumlu)
- Sadece **HTML, CSS ve JavaScript** kullanılarak geliştirilmiş

##  Kullanılan Teknolojiler
- **HTML5** → Form yapısı için
- **CSS3** → Dalgalı animasyon ve stil için
- **JavaScript (ES6)** → Input odaklanma olaylarını kontrol etmek için
